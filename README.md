# Gamepad Haptics PCM Extension

[Read the proposal](https://immersive-web.github.io/gamepad-haptics/) · [Specification source](index.bs) 

This repository contains an incubating proposal to extend the [Gamepad API](https://w3c.github.io/gamepad/) with support for custom haptic waveforms. The proposed extension allows applications to send pulse-code modulation (PCM) data from a Web Audio `AudioBuffer` to compatible gamepad haptic actuators, enabling richer feedback for games and immersive experiences.

## Status

This proposal is under incubation. The API and its behavior are subject to change as use cases, implementation experience, and feedback are gathered. It is a work in progress and is not a W3C Recommendation.

The current plan is for this work to become a **joint deliverable of the Immersive Web Working Group and the Web Applications Working Group (WebApps WG)**. The scope and arrangements for that joint deliverable remain to be agreed by the groups.
